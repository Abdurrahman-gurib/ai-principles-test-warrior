# AI Principles Test Warrior (SIS 6116)

Interactive revision site for the SIS 6116 AI Principles class test (whole module, weeks 1-10).

- Narrated video lessons with live subtitles (browser text-to-speech), for every topic
- Simple explanations, memory hacks and exam tips
- Full notes with exam-style questions and model answers (hide/reveal practice mode)
- Quizzes, flashcards, a 4-day plan and a cheat sheet
- Calculation Lab: BFS/DFS/UCS/Greedy/A* tracer, DFID, entropy & information gain, perceptron rule, backpropagation, simulated annealing, genetic algorithm, CSP forward checking, search-space counting
- Two timed mock tests in the Sample Test format

Plain HTML/CSS/JS; no build step. Open `index.html` or visit the GitHub Pages site.
